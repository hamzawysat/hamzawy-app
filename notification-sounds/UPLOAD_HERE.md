# Notification sound uploads

Upload the notification sound files you created here.

- Preferred formats: `.mp3` or `.ogg` (`.wav` is also acceptable).
- Keep the original file unchanged; do not rename or convert it before uploading.
- You can upload more than one candidate sound if you want me to compare them.

After uploading, send me the link to the uploaded file or tell me its filename so I can inspect it.

This folder is only for collecting the sound assets. No app code, notification settings, build, or deployment has been changed.
